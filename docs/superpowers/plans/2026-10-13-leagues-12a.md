# Slice 12a: league tables, the reader and the roster - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Slices 10 and 11 land first: rebase onto them before Task 6 and thread their loaders too.

**Goal:** leagues exist - the four tables, every tournament's public league, the selected league per (player, tournament) - the production-copy reader carries them, and every table sportbet scopes to a league reads its players through one roster. This ends R-73 (#29, part 1 of 3).

**Architecture:** The domain owns the league records, their invariants and `leagueRoster` (listed, then `isGuest <= viewer`). `packages/db` stores the selection as `tournament_players.selected_league_id`, tied by a composite FK to the membership, and answers every player set through `loadRoster(db, tournament, scope, rules)`, which `loadTournamentStanding` calls. `/leaderboard` and the hub panels ask for `'whole-tournament'`, the tournament page for `'public-league'`, the dashboard and slices 10-11's pages for `{ selectedBy: viewer }`. `apps/web` fills the existing `LeagueSwitcher` and answers `/leagues/switch` with a 303.

**Tech Stack:** TypeScript, Zod, Drizzle on Postgres 18, Next.js App Router, React, Vitest (unit, db, component, feature), Playwright; the reader's MySQL dump and sportbet's own image for parity.

**Spec:** `docs/superpowers/specs/2026-10-12-leagues-design.md` (Split > 12a). Rulings R-73, R-87 (data), R-103, R-25 (data).

## Decisions taken while planning (refine the spec; record them in it in Task 12)

1. **Writers keep their signatures.** `ensurePublicLeague(tx, tournament)` returns the tournament's public league, creating it (named after the tournament, generated id) when there is none - sportbet's `TournamentRegistrationService::register` does the same `firstOrCreate` (`:85`). `saveTournamentPlayers` and `registerForTournament`'s `writeJoin` call it, insert the public membership where missing, and select it on insert only. So no existing test or caller changes, and the reader (which saves the public league under sportbet's id first) is found, not duplicated.
2. **The selection is written apart from the status.** `TournamentPlayer` (a scoring status) gains nothing. `saveLeagueSelections(db, tournament, selections)` writes chosen selections after the players (the reader); `selectLeague` (Task 9) writes one under the lock.
3. **The FK on the selection is `NO ACTION`, not `RESTRICT`,** so an account deletion's cascades (slice 17) remove the membership and the `tournament_players` row in one statement, while removing a selected membership alone still fails.
4. **`league_members` keeps an identity id** (sportbet's, `overridingSystemValue`; `paid[memberId]` posts it in 12c), unique (league, player). `leagues`, `league_members`, `league_invites` and `messages` join `IDENTITY_TABLES`.
5. **CHECKs follow sportbet's columns, not its forms:** a name 1-255 characters (varchar(255); the 100 limit is 12b's form), beneficiary up to 70, IBAN up to 34, message up to 255, fee and penalty step from 0, paid cents 0..99 999 999 (`decimal(8,2)`, `min:0`). If the first `--keep` run on the owner's PC finds a production row outside one, the CHECK loosens before merge (parity beats the nicer rule).
6. **Three migrations:** the tables and a nullable `selected_league_id`; a custom data step (`db:generate --custom`); `selected_league_id` not null. Each reviewed and committed.
7. **The viewer scope falls back to the public league at full-member level** for a viewer who plays no part in the tournament (only reachable by an admin or a stale tournament; `/main` already sends a non-player home).
8. **Parity ranks each league twice:** with every member visible (today's oracle) and at full-member level (`getAllUserPoints($league, 0)`), the new code's side through `leagueRoster`.

The data step (`00NN_leagues-fill.sql`), hand-written:

```sql
insert into leagues (tournament_id, name, is_public, created_at)
select t.id, t.name, true, now() from tournaments t
where not exists (select 1 from leagues l where l.tournament_id = t.id and l.is_public);
insert into league_members (league_id, player_id, is_admin, is_guest, joined_at)
select l.id, tp.player_id, false, false, now()
from tournament_players tp join leagues l on l.tournament_id = tp.tournament_id and l.is_public
on conflict (league_id, player_id) do nothing;
update tournament_players tp set selected_league_id = l.id
from leagues l where l.tournament_id = tp.tournament_id and l.is_public and tp.selected_league_id is null;
```
